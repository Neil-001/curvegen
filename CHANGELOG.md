# 1.0.0

Curve Generator 1.0.0 is the first release. It runs on Minecraft 1.21 to 1.21.11 with Fabric.

## Features
- Ellipses, equation plots and Bézier curves, built from full blocks, slabs, stairs, trapdoors, fences, glass panes and walls
- Upright builds, like a wall, and flat builds, like a floor
- A preview that shows the exact blocks before anything is placed
- Hologram placement with undo, Replace and Carve
- Export to a Litematica schematic
- Block choices for each piece type, with colour matching against the loaded textures
- A count of every block the build needs
- Presets that save a shape with its block choices
