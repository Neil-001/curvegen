# Client screens

## Controls and layout

- A number field's width includes its arrows. Wheel input includes the arrows and calls the same responder as typing. In a scrollable point list, offer the wheel to focused fields first and use it to scroll the list otherwise. Return as soon as a right-click callback runs because it can rebuild the widget list.
- Keep 3D colour controls under the preview to leave room for the extra shape tabs. In the bottom bar, try equal widths for action buttons first and fall back to individual text widths. Reserve space for the widest paint source in the Blocks tab so the row stays put when the source changes.
- Tighten row spacing on short screens to clear the bottom buttons. Start the colour picker's closest-block list alongside the title to fit all piece types. Leave space for point lists above the preset buttons and for the paint status below its controls. The 3D point list uses wheel steps because the three coordinates leave no room for arrows. Keep surface points labelled by row and column because they belong to a grid. Combine the 3D curve's hollow and capped settings in one Shape control to leave room for its point list.
- Synchronize dragged points and derived sizes into unfocused fields only. Scroll the list to a dragged 3D point so its coordinates stay in view. Hold the point at its original camera depth and keep the grab offset so it stays under the cursor. For torus edits, scale from the dimensions at focus entry to avoid rounding and clamping on partial input. When unlocking a valid 3D equation's scale, copy the derived dimensions so its shape stays the same.
- Keep the pixel-drawn arrows and settings cog crisp at small GUI sizes. Use dark bands behind hints and status text for contrast against sky and snow. Paint status, image-drop hints and the radial footer have room for two lines. Put the complete text in the tooltip when it is cut. Shorten long image filenames in the middle to retain their extensions.
- Put focus on dialog text and select it so typing replaces the suggestion. Use the dialog title as the field's narration label. Give compact fields without visible labels a tooltip. Draw a modal over its parent without forwarding hover or input. Start a new render stratum so the modal covers parent items.
- Settings opens Minecraft's key binding screen and scrolls to the mod's category because the vanilla screen shows all categories. Block Picker sorts by the colour chosen in the colour picker, falling back to the current block's colour.

## Previews and counts

- Screens share one preview worker. Drop superseded 3D solves so they do not hold up the next view. In the main screen, let a solve finish after 400 ms of dropping work so continuous editing still shows blocks. Update the ideal outline from current settings while the blocks catch up.
- Capture the paint catalog and face colours on the client thread before submitting work. Keep the input settings used for comparisons separate from the 2D solver's mutable copy. Keep the last painted preview of a 3D solve during repaint. The 2D Paint and Pattern Library previews also keep their completed texture while a replacement is pending. Use fresh paint for export. Include the Chroma matcher version in paint freshness so changes to matching rules repaint the preview.
- Use Block colours for paint colours. Use the settled geometry for holes in every colour mode. Count holes out of the totals, using the front layer for the 2D canvas status. Group unpainted 2D states by their display names, and painted entries by resolved block, including the Blocks tab fallback. Use the preview's colours and silhouettes for count icons. On narrow canvases keep the percentage when the full error line is too wide.
- Give each preview texture its own ID because parent and child screens can both draw. Release textures when screens are covered and recreate them when drawing resumes. Fit again when the viewport or the shape's box changes. A padding-only change in the main preview keeps the player's view. Use screen pixels for 3D rasterization, lowering the scale for large canvases to cap raster work. Reuse the 3D texture while the viewport, camera and draw inputs stay the same to avoid rasterizing and uploading on idle frames.
- Preview presets from the current orientation, depth and piece choices, with saved settings applied on top. The Blocks toggle controls whether the preview and load use the preset's blocks and paint. Cache by preset and that effective choice. Cancel 3D work for a preset when the preview target changes.

## Paint and libraries

- Leave the Pattern controls visible when Paint is Off and keep its chooser usable. Choosing a pattern turns paint on. Keep the common material option in a fixed row, with a separate saved value for each source. Refresh the displayed default fit once a preview determines whether the 2D shape is a line. Turn accepts any whole degree by typing, while the arrows and wheel move to a multiple of 15 degrees and wrap at a full turn.
- A source cycler cannot disable one entry. Without Chroma Studio, skip Gradient and explain the dependency in the tooltip. Keep the selected source visible when saved settings already use Gradient, with its controls disabled. A 3D equation can use projected patterns and the Up and Out gradient directions. Mixes use block positions, so their pattern mapping stays disabled.
- In each chooser, surface the current item if it is absent from its library so a saved preset remains usable. Include the current pattern as a mix source even if it is unsaved. A saved gradient may contain blocks Curve Generator cannot place. Mark them in the tooltip because painting uses the closest placeable blocks.
- Use whole pixels per cell for small pattern thumbnails so their edges stay sharp. Choosing a library row applies the pattern before the parent rebuilds. A dropped image needs Chroma Studio for colour matching and is released when its import dialog closes. Keep the drop error until the next attempt and show the full filename in its tooltip.
- For a colour-only pattern, the paint status reports colour matches, including matches to the material picked by One material per colour. The pattern has no original blocks to replace.

## Radial input

- Keep the world live behind the menu and numeric input so hologram edits are visible. A keyboard binding can be held or tapped before the new screen gets an event. Ignore repeat presses from the key that opened a screen and check its physical state for a missed release. A mouse binding does not repeat, so its next click can select a wedge or close the menu from the centre.
- In Hold mode, releasing the key selects the current wedge. Opening a submenu leaves it open for clicks. Return to the root if a hologram ends while one of its submenus is open. Group consecutive wheel changes to the same option into one undo step.
