# Listing

The Modrinth and CurseForge project pages, and the artwork they share.

- `description.md` is the description, which Modrinth takes as it is. `curseforge.html` is the same text as CurseForge's HTML, written by `art/curseforge.py`, because CurseForge's markdown drops `<center>` while its HTML keeps a centred paragraph. The script also points the Fabric API badge and the Chroma Studio links at CurseForge and uses PNG badges. Run `python3 listing/art/curseforge.py` after editing the description. The build checks that the two match. It needs the `markdown` package.
- `media/` holds the images the description shows, which both pages load from `main`. A new or changed image shows on the pages once it's merged there. `media/icon.png` is the project icon instead, which only changes when the `Listing` workflow runs (below).
- `gallery/` holds the screenshots for the two sites' galleries, at most nine, each taken in the game at 1920 by 1080 with the default textures. Nothing draws them. Its `README.md` has each one's title and description. The `Listing` workflow (`.github/workflows/listing.yml`) uploads them to Modrinth along with the description. CurseForge's page and gallery are done by hand: paste `curseforge.html` and upload the pictures.
- `art/` draws the images in `media/` from the mod's solvers. Run `python3 listing/art/render.py`. It needs JDK 25 and Pillow, and `./gradlew build` run once before it. Its functions marked unused, painting among them, drew pictures the listing no longer shows, and nothing runs them. Each says how to bring its picture back.

After a change to the description or gallery has merged, run `gh workflow run listing.yml --ref main -f dry_run=true`, check what it says it would do, then run it without `dry_run`. It leaves a gallery picture alone when Modrinth already shows one with the same title, and `-f replace=true` uploads those again. It never removes a picture: one taken out of `gallery/README.md` or renamed there stays on Modrinth until it's deleted on the project's gallery page, and a picture it leaves alone keeps its old place in the order. It also sets the project's icon from `media/icon.png`, the mod's icon as a 256 by 256 PNG. `render.py` writes that file and the mod's own `src/main/resources/assets/curvegen/icon.png` together, so they stay the same. CurseForge's project icon is uploaded by hand, from the same file.
